# 04. 추격 설계 — 쫓아오는 것, 숨는 곳, 따돌리는 법

> **한 문단 요약**: 추격은 총 14회(합계 1,560초, 약 26분)다. 대형(2분 이상) 4회, 중형·소형 10회. 쫓아오는 것은 센서등 머리의 '한 번 더'와 층마다 한 명의 서브 귀신이다. 플레이어가 할 일은 언제나 같다: **시야를 끊고, 멈추거나 숨고, 필요하면 팥으로 막고, 종료 지점까지 가라.** 추격이 끝나면 안전지대와 이완 구간이 열린다. 잡혀도 추격 시작 지점에서 바로 다시 한다. HUD 문구는 추격 중에도 바뀌지 않고 붉은 테두리와 '도망' 아이콘만 켜진다.

---

## 1. 추격의 약속 (플레이어와의 계약)

1. **예고 신호는 1:1로 정해져 있다.** 모든 고정 추격은 시작 5초 전에 아래 신호가 나온다(한 번 더 추격은 둘 이상).

| 신호 | 의미 |
|---|---|
| 안내방송 "딩동댕" | 한 번 더 추격 예고 **전용**. 분위기 방송은 "뚜—" 마이크 점검음으로 시작한다. |
| 센서등이 한 칸씩 연속 점등 | 한 번 더 접근. 단발 점등은 연출이다. |
| 먼 +1 노크 | 한 번 더가 같은 층에 있다. |
| 서브 고유음: 카트 "끼익" / 우편함 "철컹" / 발 끄는 소리 / 첫 호출 "지우야" | 해당 서브 추격 5초 전 |

   점프스케어 5회의 그 순간(03번 문서 9절)은 예고 없는 예외이고, #5는 점프스케어가 곧 시작이다. 퍼즐 오브젝트 반경 6칸 안에서는 확률 출현이 없다.
2. **상태가 보인다.** 한 번 더의 센서등 머리 색이 곧 경계 수준이다(푸른 대기등=배회, 흰 점등=추적, 점멸=혼란).
3. **길이 보인다.** 추격 중에는 숨을 수 있는 가구가 은은하게 빛나고, 화면 가장자리가 붉게 뛰며 '도망' 아이콘이 켜진다.
4. **잡히면 바로 재개.** 게임오버는 '층간소음 민원 접수증'. 추격 시작 지점에서 5초 유예 후 재개한다.
5. **안전한 첫 조우.** 서브 귀신은 추격이 켜지기 전에 10초 시연 장면(최정숙은 센서등에 멈춘 카트, 이강호는 유리 너머 소리에 고개를 돌리는 모습, 한만수는 전조등에 얼어붙는 모습, 신하영은 모니터에서 호출에 "대답"한 환영이 사라지는 모습)을 보여 주고 규칙을 수첩에 자동 기록한다. #10은 첫 호출의 실패 판정을 유예하고 자막 "입력 금지"를 띄운다.
6. **끝이 분명하다.** 모든 추격에는 종료 조건이 있다(4절 표). 종료 큐는 공통으로 **소리 정지 + 붉은 테두리 해제 + 안전지대 스탠드 점등**이다. 이 순간이 곡선 위의 이완 지점이다.

## 2. 도망치는 방법 (공통 도구)

| 수단 | 효과 | 비고 |
|---|---|---|
| 시야 끊기 | 시야 원뿔 밖으로 나간다 | 문을 닫거나 코너를 돈다. 추적을 수색으로 떨어뜨리는 첫 단계다. |
| 멈추기 | 움직임에만 반응하므로 2칸 밖에서 정지하면 못 본다 | **배회·수색에서만 통한다.** 추적(흰 점등) 중에는 먼저 시야를 끊어야 한다. 한 번 더가 3+1 뒤 원반을 도는 **스캔 펄스**("띡띡" 예고) 동안은 체온 감지 반경이 3칸이다. #3 #8 #12 #14에는 정지가 통하지 않는 구간(직선 복도, 스캔 상시)이 있다. |
| 숨기 | 옷장, 침대 밑, 욕조, 신발장, 책상 밑, 차 밑, 분리수거함, 미끄럼틀 터널 | 아래 판정 규칙을 따른다. |
| 팥 라인 | 12초 동안 건너지 못한다 | 1봉=1라인, 소지 최대 3봉. 챕터가 갈수록 짧아진다. |
| 미끼 노크 | 먼 벽을 두드리면 그쪽으로 간다 | 소음 2. |
| 던지기 | 소리 나는 물건을 던져 이강호를 유인한다 | 한 번 더는 반응하지 않는다. |
| 센서등 끄기 | 움직이지 않으면 5초 뒤 소등 | 어둠에서 시야가 좁아진다. |

**숨기 판정은 결정적이다(확률 없음).** 낮은 곳(침대 밑, 차 밑, 욕조, 분리수거함, 미끄럼틀 터널)은 한 번 더가 3+1 후 3초 멈췄다가 지나간다. 높은 곳(옷장, 신발장, 로커)은 한 번 더가 수색 상태이거나 마지막 시야 방향 3칸 안이면 직접 열어 확인한다(발각). 같은 추격 중 이미 숨은 곳은 수색 때 확인 대상이 된다. **숨기의 비용**: 가구 안은 시야가 좁아지고 숨 게이지가 10초 줄어 0이 되면 숨소리 소음 1이 난다. 나가도 되는 때를 아는 방법은 확인 노크 하나뿐이라 확인이 필수 선택이 된다.

**숨은 동안의 확인 노크**: [1]을 **약하게** 두드린다(소음 1). 에코=이 방에 없음. 먼 +1=방 밖에 있음. **큰 +1=이 가구 바로 앞.** 한 번 더는 3+1 뒤 3초를 멈추고, 이 3초가 대답 구간이라 화면에 [대답 금지]가 뜬다. 이때 대답하면 발각된다. 그 밖의 노크는 확인으로 판정한다.

### 상세

**#1 붙박이장**: 한 번 더 위치 타임라인은 붙박이장 속 → 안방 문 3+1 → 거실 → 현관 앞(도어락 "띡", 현관 막힘) → 욕실 문 앞 3+1과 3초 정지 → 현관 쪽 복귀이고, 이때 안방 점검구가 "철컥" 열린다. 경로는 안방 → 거실 → 욕실 → 안방 사다리. 숨을 곳은 욕조 커튼. 까치발로 숨어 3초를 침묵한다(선택으로 욕실 문 앞 팥 라인). 배우는 것: 이동 소음, 숨기, 확인 노크, 팥.

**#2 2601호의 불**: 2601 거실 → 복도 센서등 3칸 → 안방 문 앞. 숨을 곳 없음. 센서등 아래에서 움직여 불을 유지하며 한 칸씩 이동한다. 배우는 것: 서브마다 규칙이 다르다.

**#3 복도 한 바퀴 (대형, 데모 컷)**: 계단실 앞 → 시계 방향 고리(약 40칸) → 문 D 모퉁이 → 문 B 앞 → 계단실 ▲. 숨는 곳은 알코브 3곳(2601호는 추격 중 잠김). 코너에서 팥 라인 첫 사용, 알코브 숨기, 한 바퀴를 돌아 뒤에서 계단실로. 거리 좁히기: 직선 복도 돌진, 고리를 반대로 도는 예측 선회. 3단계 전신 공개 + "윗집인데요."

**#4 우편함**: 우편함 복도 → 로비 중앙 → 경비실 앞. 숨을 곳 없음. 까치발로 움직이거나 동전·우편물을 던져 유인한다.

**#5 경비실 책상 밑**: 경비실 → 뒷문. 숨을 곳은 책상 밑(낮음)과 로커(높음). 숨음 → 확인 노크(선택) → 3+1 후 3초 침묵 → 뒷문.

**#6 로비 루프**: 로비 중앙 → 우편함 복도 → 계단실 앞 → 엘리베이터 홀 → 로비 중앙(고리) → 경비실 휴게실. 숨을 곳은 우편함 벽 틈, 화분 뒤. 이강호에게는 까치발, 한 번 더에게는 멈춤이 필요한 구간에서 반대편에 우편물을 던져 이강호를 유인한다. 엘리베이터 버튼으로 문을 열어 두면 한 번 더가 확인 노크로 12초를 쓴다(미끼). 거리 좁히기: 막힌 문 자동 개방, 코너 선회 예측.

**#7 스티커 차**: U자 통로. 숨을 곳 없음. 한만수를 마주 보며 옆걸음으로 번호판을 읽는다(P9). 손전등은 멈추게 하지만 배터리가 닳는다. 7421 차를 찾으면 끝난다.

**#8 지하 대추격 (대형)**: 배전반 → 주차 구역 A~C 고리 → 비상계단 루프 1회 → 정비실. 숨을 곳은 차 밑. 한만수는 정면 고정이나 손전등으로 멈추고, 한 번 더는 차 밑과 팥 라인으로. 차량 경보기를 노크로 울려 미끼를 만든다. 거리 좁히기: 비상계단 문 자동 개방, 막다른 통로 회피, 스캔 펄스 상시.

**#9 기계실**: 기계실 → 비상 통로 → 셔터 앞. 숨을 곳은 소화 펌프 뒤 낮은 틈, 차 밑. 센서등을 끄고 멈춘다. 안전지대에서 나온 직후 방심한 구간을 노린 급습이다.

**#10 분리수거장**: 호출 주기 약 13초(호출 2초 → 대답 창 3초 → 쉼 8초) × 6번 = 약 80초. 숨을 곳은 분리수거함 안(대답 창 전에 미리 들어가야 한다). 대답 창에는 입력하지 않고 쉼에 이동·수색한다. 호출이 가까워질수록 후드 그림자가 한 칸씩 나타난다. 6번째 호출("한지우 고객님 맞으십니까?")을 침묵으로 넘기면 휴면한다.

**#11 놀이터**: 놀이터 → 정자 → 화단 → 경비 초소. 숨을 곳은 터널 미끄럼틀, 정자 아래, 관목. 숨기와 정자 기둥 미끼 노크.

**#12 단지 일주 (대형)**: 경비 초소 → 정문 앞 → 놀이터 → 비상계단 입구 앞 → 분리수거장 관리 부스. 숨을 곳은 관목, 터널 미끄럼틀(이미 숨은 곳은 수색당한다). 05:10 엄마의 9번째 전화는 **벨소리가 먼저 울리고** 항상 신하영의 쉼 구간에 온다. 받으면 벨이 멈추고 8초 동안 속삭여 통화하며, 안 받으면 벨이 한 번 더를 부른다. 신하영의 엄마 목소리 흉내에는 입력하지 않는다. 팥 라인 1회, 정문 앞 센서등 끄기. 거리 좁히기: 순환로 코너 선회 예측, 목소리의 방향 교란, 직선 구간 돌진.

**#13 계단실 끝**: 계단참 루프(▲만 이어짐, 3바퀴). 숨을 곳은 소화기함 뒤. 센서등을 끄고 멈춘다. 옥상 문 앞 계단참에 닿으면 한 번 더가 수색으로 내려가고 **P12는 그 뒤에 푼다.**

**#14 옥상 새벽 (대형, 최종)**: 해치를 중심으로 한 원형. 숨을 곳은 빨래 건조대 시트 뒤, 환기구 뒤(물탱크실은 비활성). 아래 [3]은 주기 25초(9번째 전화 응답) / 45초(미응답), **응답 창 5초**이고 해치 반경 1칸 안에서만 닿는다. 놓치면 다음 주기를 기다리고 오답이면 현재 세트만 초기화된다. 도움은 호명한 서브만 쓰며 HUD 도움 아이콘 4개를 지정 버튼으로 발동한다(각 1회). 세트 사이 '해치 직전'에 쓰고 마지막 하나는 P14 직전에 자동으로 쓰인다. 최정숙은 조명으로 3초 눈멀게 하고, 이강호는 반대편 환기구를 두드려 유인하고, 신하영은 목소리로 3초 세우고, 한만수는 정면으로 5초 얼린다. 거리 좁히기: 해치 반대편 지름길 선회, 눈높이 접근 연출, 지우의 노크 리듬 따라 하기.

## 5. 배회 조우와 거짓 경보

고정 14회 외에 **배회 조우**(확률 출현)를 둔다. 구역은 Ch1 고리 복도 / Ch2 로비·홀 / Ch3 주차 구역 / Ch4 순환로(Ch5 없음)이고, 추격자는 한 번 더, 쿨다운 180초, 최대 40초, 시야를 끊어 수색으로 전환하면 종료된다. 먼 +1과 센서등 연속 점등으로 5초 전에 예고하며, 구역별 최대 2회, **챕터 합계 상한 80초**다. 퍼즐 오브젝트 반경 6칸, 안전지대 반경 4칸, 04:10 정적, 호출·대답 창에서는 나오지 않는다. 챕터 권장 시간을 넘기면 쿨다운이 90초가 된다. **거짓 경보**는 Ch2~Ch4마다 1회, "딩동댕"만 나오고 추격이 없다.

# Project ICHOR 스토리 요약 (1페이지)

> 프로듀서 검토용. 상세는 `01_world.md` ~ `07_items_lore.md`.

## 제목 후보
1. **ICHOR: 마지막 화로** (The Last Hearth)
2. **ICHOR: 문과 화로** (Door and Hearth) — 헤스티아와 헤르메스를 한 쌍으로 묶는 호메로스 찬가에서 따옴
3. **불씨지기** (Pyrphoros)

## 로그라인
신들의 화로가 꺼진 지 아흐레, 추락한 헤르메스(Hermes)의 마지막 불씨를 받은 **죽어도 화로로 돌아오는 불씨지기**가 신들의 집을 돌며 올림포스(Olympus)의 불을 다시 지피려 하지만, 불을 끈 것은 적이 아니라 "문을 열어 달라는 간청"이었다.

## 세계관
- 올림포스 중앙 화로가 꺼지자 신들의 피 이코르(ichor)가 검은 비로 내리고, 닿은 짐승과 사람은 굶주려 일그러진다. 신들은 굶주려 침묵하고, 저승문이 닫혀 죽은 자들은 **그림자 없는 자**가 되어 맴돈다.
- 화로(Hearth)는 집의 중심이다. 주인공의 불씨로 지핀 화로는 주인공을 식구로 인정해 죽으면 그곳에서 깨어난다.
- 괴물은 신에게 버려진 피해자다. 보스를 쓰러뜨리면 본래 **이름을 불러** 애도한다.
- 테마는 환대(Xenia)·간청(Hikesia)·서약(Horkos). 세 법이 충돌하며 질서가 무너진다.

## 주인공
**불씨지기(Pyrphoros)**. 성별 선택이 가능한 말수 적은 고아 화덕지기. 대사는 수락/거절/침묵 선택지와 이름 부르기뿐이다. 이미 한 번 죽었다는 사실을 아직 모른다.

## 3막 요약
| 막 | 내용 |
|---|---|
| 1막 **불씨** (아르카디아, 델포이, 키타이론) | 헤르메스에게서 불씨와 샌들을 받고 화로를 지핀다. 베일 쓴 손님이 아테(Ate)임이 드러나고, 불이 습격이 아닌 내부 충돌로 꺼졌음을 알게 된다 |
| 2막 **굶주림** (렘노스, 에게 해, 저승 문턱) | 헤스티아(Hestia)가 진실을 고백한다. 아테를 화로에 앉힌 것은 그녀였고, 제우스의 서약이 이를 막아 불이 꺼졌다. 주인공이 이미 죽은 자이며 불씨가 죽음을 빌려 쓰고 있다는 반전 |
| 3막 **문턱** (밤의 집, 올림포스) | 쫓겨난 딸 아테는 복수자가 아니라 집에 돌아가려는 자다. 문을 닫고 질서를 지킬지, 열고 신들의 시대를 끝낼지 선택한다 (엔딩 3종) |

## 슬라이스: 리카이온 고지 (Lykaion Heights, 1장 "재의 식탁")
| 항목 | 내용 |
|---|---|
| 지역 | 아르카디아의 늑대 산 약 1km². 마을(남) → 숲(서) → 능선(동) → 정상(북) |
| 화로 | 7개. 화로 반경에서는 검은 비가 그치며 지도 위의 '비 그친 구역'이 진행도 |
| 적 | 일반 6종, 미니보스 2(황금뿔 암사슴, 에리만토스 멧돼지), 보스 2(리카온 늑대 왕, 칼리스토 곰) |
| 신의 축복 | 아르테미스, 헤르메스, 제우스 각 2개 = 6종 |
| 퀘스트 | 메인 10단계 + 서브 4개 |
| 첫 10분 훅 | 신이 죽는다 → 불씨를 받는다 → 첫 전투에서 필패 → 화로에서 깨어난다. 3가지 질문(왜 말끝을 흐렸나/왜 나만 돌아오나/왜 마을 사람들은 그림자가 없나) |
| 1장 엔딩 | 마을 사람들이 모두 죽은 자임이 밝혀지고 제우스의 모순된 목소리와 베일 쓴 손님이 2장을 연다 |

## 상업적 강점 3가지
1. **즉각적이고 명료한 훅**: 첫 5분에 신의 죽음과 첫 패배, 부활이 이어진다. 메인 동기는 한 줄("불씨를 올림포스까지")이고 진실은 아이템과 환경에 흩뿌려진다.
2. **시스템과 서사의 결합**: 부활(화로), 활공(샌들), 축복(계약), 보스 마무리(호명)가 모두 한 주제 아래 의미를 갖는다. 화로 반경의 비가 그치는 연출이 진행도 UI를 겸한다.
3. **복수가 아닌 애도의 신화**: '신을 죽이는 전사' 문법을 피한 감정적 차별점이다. 반전(마을 사람, 주인공의 죽음, 아테의 정체)이 단계별로 나뉘어 DLC·후속 확장에 적합하다.
